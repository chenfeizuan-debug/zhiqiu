导入与常见问题

把 .xbs 导入香色闺阁

方法一（推荐）：下载后在系统「文件」App 里找到那个 .xbs，长按 → 共享 → 选「香色闺阁」，自动导入。

方法二：香色闺阁 → 书源管理 → 导入 → 从文件导入 → 选中同一个 .xbs。

导入后在书源列表里看到同名书源即成功；合并版会一次出现三条。

少年梦导入后为什么搜不到正文

发现页里有一个分类叫 「① 登录账号（先点这里）」，点进去等它转一圈，看到「✅ 账号已登录」就好了。这一步把共享 Token 绑到你的账号上，只做一次。

「② Token 状态」可以随时看到期时间和剩余次数。

领取链接打开是 403 / 用户已存在 / 空白

403 口令错误：三个口令有一个字不对，回群里核对当天口令。

400 用户已存在：这个设备号领过了。再点一次「生成领取链接」（每次换新设备号），用新链接领。

空白页：接口有时慢，等几秒；或换 Safari / Chrome 打开。

次元姬提示太快了 / 看不了下一章

次元姬限制每账号每分钟 80 章，连读太快会触发，等一分钟再刷新目录。游客额度更小，注册正式账号额度更高。

下载没反应 / 点了没动静

生成后页面会自动刷新一次，让 iOS 底部工具栏的下载图标露出来；还是没动静就点结果区的「页面没反应？点这里刷新」，或换 Safari / Chrome。文件已经在系统「下载」里了。

全程在本机处理，无后端、无上报：把模板里的凭证槽位换成你粘的那串，再按香色闺阁 2.56.1 的容器格式（BTEA）加密打包成 .xbs。生成后的文件里含你的 JWT / Token，别发给别人。
